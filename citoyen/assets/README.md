# Assets Folder

This folder should contain the following image assets for your Expo app:

## Required Assets

1. **icon.png** - App icon (1024x1024px recommended)
   - Used for: iOS and Android app icon
   - Location: `./assets/icon.png`

2. **splash.png** - Splash screen image
   - Used for: App launch screen
   - Location: `./assets/splash.png`

3. **adaptive-icon.png** - Android adaptive icon foreground
   - Used for: Android adaptive icon
   - Location: `./assets/adaptive-icon.png`

4. **favicon.png** - Web favicon
   - Used for: Web app favicon
   - Location: `./assets/favicon.png`

## Note

These asset references have been temporarily removed from `app.json` to allow the app to run. Once you add the actual image files, you can uncomment the asset references in `app.json`.
