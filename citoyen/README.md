# KattanX - Portail Citoyen (Mobile)

Application mobile React Native pour le portail citoyen KattanX.

## 🚀 Démarrage rapide

```bash
# Installer les dépendances
npm install

# Démarrer l'application
npm start
```

Pour plus de détails, consultez **[START_HERE.md](./docs/START_HERE.md)** ou **[INSTALLATION.md](./docs/INSTALLATION.md)**.

## 📱 Fonctionnalités

- **Authentification** - Connexion et inscription avec OTP
- **Profil** - Gestion des informations personnelles
- **Dossier** - Documents administratifs (DAF)
- **Propriétés** - Gestion des biens (titres fonciers, véhicules)
- **Dénonciations** - Système d'alertes citoyennes avec preuves
- **Plaintes** - Dépôt et suivi de plaintes
- **Revenus** - Gestion des gains et transferts
