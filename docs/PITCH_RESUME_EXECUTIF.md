# KàttanX - RÉSUMÉ EXÉCUTIF PITCH
## Plateforme Nationale de Sécurité et Justice Civique - GovAthon 2025

---

## QU'EST-CE QUE KàttanX ?
Plateforme unifiée qui digitalise la sécurité publique au Sénégal en connectant **Citoyens**, **Forces de l'Ordre** et **Contrôleurs** via l'IA et le temps réel.

---

## LE PROBLÈME
- Vérification identité : **12 minutes** (données fragmentées)
- Fausses alertes : **40%** (pas de triage)
- Participation citoyenne : **<5%** (pas d'incitation)
- Corruption : **Difficile à détecter** (pas de canal sécurisé)

---

## LA SOLUTION EN 3 PILIERS

### 1. PORTAIL CITOYEN (Mobile)
- **Inscription** : Vérification ANCEC + OTP WhatsApp + Biométrie
- **Dénonciations** : Signaler avec preuve (photo/vidéo) + localisation
- **Innovation** : **Loi 13/2025** = Citoyen signale corruption → enquête → 10% fonds récupérés
- **Alerte Urgence** : Bouton "Je suis en danger" → brigades < 10km notifiées

### 2. PORTAIL AGENT (Mobile)
- **Vérification 3 méthodes** : CNI (3 sec) / Matricule auto / Photo (IA reconnaissance faciale 1:1)
- **Résultat** : Statut judiciaire + amendes + recherche → demande autorisation arrestation
- **Alerte BOLO** : Agent crée alerte → diffusion 2 sec → tous agents zone reçoivent
- **GPS temps réel** : Position agents partagée (service on/off)

### 3. PORTAIL CONTRÔLE (Web)
- **Dashboard** : Stats temps réel + carte agents + alertes récentes
- **Surveillance** : Caméras Safe City + **IA analyse vidéos** → détection automatique menaces
- **Gestion** : Assignation missions + validation alertes
- **Prédiction** : Heatmaps criminalité → patrouilles proactives

---

## TECHNOLOGIES
- **Backend** : Django 5.0 + PostgreSQL (Supabase) + MinIO (S3) + Google Gemini AI
- **Mobile** : React Native + Expo + TypeScript + Biométrie ISO
- **Web** : React + Vite + Tailwind + Leaflet (cartes)
- **Sécurité** : JWT + 2FA + OTP + Chiffrement
